Build agents by connecting blocks on a native desktop canvas. Jev chooses among connected paths; research, generated documents, and email context flow through the workflow.

### Downloads

- **macOS:** choose `arm64` for Apple Silicon or `x64` for Intel. Open the DMG and drag Skarva to Applications, or use the ZIP.
- **Windows x64:** use `setup.exe` for a per-user installation and Start-menu shortcut, or extract the portable ZIP.
- **Linux x64:** install the DEB on Debian/Ubuntu, or extract the tarball and run `./skarva`. Desktop libraries, graphics drivers, and a Secret Service keyring are required.

These builds are currently ad-hoc signed on macOS and unsigned on Windows; Gatekeeper or SmartScreen may flag the developer as unverified. They do not include automatic in-app updates.

Bring your own API keys. Start with the Text workflow template and connect one AI provider. See [setup and current limits](https://github.com/david-lockley/skarva/blob/main/docs/SETUP.md).
