## 0.1.0 — unreleased preview

- Native canvas with connected blocks, pan/zoom, group selection, and duplication.
- Jev routing between actions, with human review for uncertain choices.
- AI text generation through OpenRouter, OpenAI, or Anthropic.
- Tavily research, local reference files, and editable Word, Excel, and PowerPoint output.
- Gmail receive/reply workflows with explicit review before sending.
- Automatic context, encrypted service credentials, project import/export, and a first-workflow template.
- macOS bundle, Windows ZIP, and Linux tarball packaging, plus platform CI checks.
- Version-tagged GitHub releases with Apple Silicon/Intel macOS ZIP/DMG, Windows x64 ZIP/installer, Linux x64 tar.gz/DEB, and SHA-256 checksums. Versions derive from Cargo.toml.

See the [release checklist](docs/RELEASE_CHECKLIST.md) for verified behavior and the platform checks still needed before distributing builds.
